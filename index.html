Every project folder must contain exactly 4 root folders. Place files only inside the correct folder to reduce confusion during handovers.

Section Five
Frame.io & Export File Naming
🏷️ Export File Naming Convention Required
The naming formula applies to files saved to Drive and uploads to Frame.ioopen full size
YYMMDD_Project Name_[ADDITIONAL INFO]_Draft 00
• Internal revision — add decimal: Draft 1.1, Draft 1.2
• External (client) revision — bump major number: Draft 1.1 → Draft 2
• Additional info examples: lowres · graded · vertical · no music
🎥 Frame.io — Check Before Creating a Project Rule
❌ Vague unsorted names  ·  ✅ YYMM – Client – Project formatopen full size
✓
Always check for an existing project before creating a new one.
✗
Do not create duplicates or variations without approval.
📅 Recurring Project Naming — YYMM Format Rule
✅ YYMM – Client – Title  ·  ❌ Month/year labels like "MAY 2025"open full size
📚 Frame.io Stacking — 2 Stacks in the Same Folder Rule
❌ Don't create separate CLIENT / INTERNAL folders  ·  ✅ All files in one folder — create 2 stacks (Internal & External) within itopen full size
⚠️
Don't separate into folders — use stacks within one folder Keep all files in one project folder. Inside that folder, stack internal drafts into one stack and client-facing exports into another.
1
Same folder for everything. Both internal and client exports live in the same Frame.io project.
2
Create 2 stacks inside that folder — one for internal drafts, one for client deliverables.
3
Only stack once you start the next version. Don't stack the active draft being reviewed.
