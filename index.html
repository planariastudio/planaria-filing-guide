Where every file goes

Folders on Drive, bins inside Premiere and After Effects, and how exports and Frame.io projects are named. Get this right and a handover takes minutes instead of a morning.

Why it is worth the effort

Filing is the one thing on this page that only helps other people. You already know where your files are. This structure is so the next editor, the supervisor checking a cut, and you in six months all find them without asking.

Part 1

Drive folder structure

Four root folders, always the same four, in every project. Files go inside the right one or they may as well not exist.

1.1

The four root folders

The rule

Every project folder contains exactly four root folders: 01 DOCUMENTS, 02 ASSETS, 03 PROJECTS, 04 EXPORT. No more, no fewer, no renaming.

1.2

01 DOCUMENTS

The rule

Three subfolders. 00 OTHER for camera reports and references, 01 BRIEF for briefs and storyboards, 02 FONT for every typeface the project uses.

1.3

02 ASSETS

The rule

Seven subfolders: 00 CLIENT ASSETS, 01 FOOTAGE, 02 SOUND, 03 STILL GRAPHIC, 04 GFX, 05 COLOR GRADED, 06 PROXY.

Never mix client assets with media you sourced

Anything the client sent goes in 00 CLIENT ASSETS and nowhere else. Stock footage and downloaded music go in 01 FOOTAGE and 02 SOUND. Mixing them means nobody can tell later what was licensed and what was delivered.

1.4

03 PROJECTS

The rule

One subfolder per application: 01 PREMIERE PRO, 02 AFTER EFFECTS, 03 DAVINCI RESOLVE.

1.5

04 EXPORT

The rule

01 INTERNAL for previews and snippets, 02 CLIENT for anything the client receives, 00 OTHERS for subtitle files, LUTs and stills.

1.6

Worked example

A real project as it arrived, and where each part of it belongs.

What arrivedWhere it goes

Part 2

Premiere Pro bins

The project panel mirrors the Drive structure. If you know one, you know the other.

2.1

Bin structure

The rule

Start every new project from this bin layout: 00 SEQUENCES at the top, then 02 ASSETS with the same subfolders as the drive.

Import into a bin, not into the root

Never leave footage loose at the top of the project panel. Drop it into its matching bin as you import. Tidying it later never happens.

Part 3

After Effects bins

Same idea as Premiere, with one difference at the top.

3.1

Bin structure

The rule

The same structure as Premiere, except compositions live in 00 COMP at the top instead of sequences.

Part 4

DaVinci Resolve

Colour only. Resolve is not where the edit happens.

4.1

Three bins, that is all

The rule

The Resolve media pool has three bins and no others: FOOTAGE, XML, REFERENCE.

Edit in Premiere, grade in Resolve

All editorial work happens in Premiere. Send the finished edit to Resolve by XML or EDL, grade it, then bring the graded footage back to 02 ASSETS / 05 COLOR GRADED.

Part 5

Frame.io and export naming

The part clients see. A wrong name here is visible outside the studio.

5.1

The naming formula

The rule

Every export, on Drive and on Frame.io, is named:

YYMMDD_Project Name_[ADDITIONAL INFO]_Draft 00

Which revisionWhat the number doesExample
Internal revisionAdd a decimalDraft 1.1, then Draft 1.2
Client revisionBump the whole numberDraft 1.2 becomes Draft 2

The optional middle piece describes the version, not the project: lowres, graded, vertical, no music.

5.2

Check before you create a Frame.io project

The rule

Always look for an existing project first. Do not create duplicates or variations of a project name without approval.

5.3

Recurring projects use YYMM

The rule

A recurring project is named YYMM – Client – Title. Never a written month and year.

5.4

Two stacks, one folder

The rule

Everything for a project lives in one Frame.io folder. Inside it, make two stacks: one for internal drafts, one for client deliverables. Do not split them into separate folders.

  1. One folder for everything. Internal and client exports share it.
  2. Two stacks inside it. Internal drafts in one, client deliverables in the other.
  3. Only stack once the next version exists. Never stack the draft currently under review, or reviewers lose it.
5.5

Handover and deletion

The rule

A handover folder is named HANDOVER – YYMMDD – PROJECT NAME. Never delete a file without approval.

6.2

The four things people get wrong

  • Client files mixed in with stock footage. They go in 00 CLIENT ASSETS.
  • Footage left loose at the root of the project panel instead of in a bin.
  • A new Frame.io project created when one already exists under a slightly different name.
  • Internal and client exports split into two Frame.io folders instead of two stacks in one.
